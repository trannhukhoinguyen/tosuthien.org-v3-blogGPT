Chào mừng bạn đến với trang web demo Where1Returns! **Where1Returns là một giao diện blog trên nền tảng Astro, lấy cảm hứng từ bố cục của ChatGPT.**

Bạn có thể viết bằng Markdown hoặc MDX và quản lý nội dung dưới dạng các tệp tin. Thanh bên quen thuộc, khu vực đọc tập trung và ô tìm kiếm giúp độc giả dễ dàng khám phá các bài viết tiếp theo.

## Các tính năng

| Danh mục             | Tính năng                                                                                                                                                        |
| -------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Giao diện đọc        | Bố cục linh hoạt (responsive), thanh bên có thể thay đổi kích thước, tùy chọn giao diện sáng/tối/theo hệ thống, xem trước tiêu đề, mục lục mở rộng, phím tắt và điều hướng phía client |
| Quản lý nội dung     | Bài viết, trang độc lập, danh mục và thẻ (tag); hỗ trợ thư mục lồng nhau, đường dẫn (slug) cố định, tệp đính kèm đi kèm và các mẫu bài viết                       |
| Nội dung phong phú   | Hỗ trợ Markdown / MDX, Expressive Code, KaTeX, Mermaid, các khối chú thích (callouts), PhotoSwipe và các thành phần tương tác                                   |
| Duyệt nội dung       | Bài viết ghim và danh sách theo trình tự thời gian, phân trang với tính năng chuyển nhanh đến trang cụ thể, ảnh bìa danh mục, đám mây thẻ, lưu trữ theo năm và nhóm liên kết bạn bè |
| Tìm kiếm trên trang  | Tìm kiếm trong bài viết, tiêu đề/mô tả, nội dung hoặc toàn bộ trang web; làm nổi bật ngữ cảnh, hỗ trợ lệnh nhanh (slash commands) và tự động hoàn thiện tiêu đề bài viết |
| Đa ngôn ngữ          | Cấu hình ngôn ngữ linh hoạt cho giao diện và nội dung; hỗ trợ sẵn tiếng Trung và tiếng Anh (tiếng Anh được dịch bởi AI)                                         |
| Chia sẻ và nguồn cấp | Hỗ trợ sao chép định dạng, tùy chọn các nền tảng mạng xã hội, tạo ảnh bìa chia sẻ bằng Satori, RSS và Sitemap                                                    |
| Thống kê blog        | Tổng số bài viết, số lượng ký tự (tổng và trung bình), tần suất xuất bản, thời điểm đăng bài đầu tiên và cập nhật mới nhất, biểu đồ nhiệt (heatmap) và biểu đồ độ dài bài viết |
| Tùy chỉnh             | Cài đặt đa dạng về giao diện, nội dung và tương tác; kết hợp với các tệp mở rộng HTML/CSS/JS trên toàn trang, cho phép bạn tùy chỉnh trang web theo ý muốn         |
